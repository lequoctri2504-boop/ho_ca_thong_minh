Hướng dẫn xuất file .bin từ Arduino IDE để nạp không dây

1
Mở dự án esp32_firmware/esp32_firmware.ino trong Arduino IDE.
2
Chọn đúng Bo mạch ESP32 Dev Module trong mục Tools -> Board.
3
Nhấn menu Sketch -> Chọn Export Compiled Binary (hoặc nhấn phím tắt Ctrl + Alt + S).
4
Sau khi IDE thông báo "Done compiling", tìm file có đuôi .bin (thường nằm trong thư mục build/... hoặc trong cùng thư mục sketch).
5
Chọn file .bin đó tại ô Nạp Firmware ở trên và nhấn Bắt đầu Nạp Firmware OTA. Mạch ESP32 sẽ tự cập nhật và tự khởi động lại trong 5 giây!
